# Lab 8: AST to Three-Address Code Generation
In Labs 6 and 7, we implemented a Lexer and Parser for MiniC.
In this lab, we will take the Abstract Syntax Tree (AST) produced by the Parser and generate the corresponding Three-Address Code (TAC).
In the next lab, we will take the generated TAC and produce SIC assembly code.


## The TAC Structure
Recall that TAC is a low-level intermediate representation that breaks down complex expressions into simpler ones.
Each TAC instruction typically has at most three operands: two source operands and one destination operand.
We allow the following instruction classes defined in `tac.py`. 
* **Control Flow**: `goto`, `label`, `if_false`, `goto_label_id`
* **Function Calls**: `param`, `call`, `return`
* **Variable Declarations**: `declare_int`, `declare_array`
* **I/O**: `read`, `write`
* **Assignments**: `=`
* **Arithmetic**: `+`, `-`, `*`, `/`

## Node Visitors
The TAC program is generated by visiting each node in the AST and emitting the corresponding TAC instructions.

## `tac.py`
The `tac.py` file contains the `TACProgram` class, which provides methods for generating TAC instructions and managing temporary variables and labels.
